HOW TO PREVIEW
Open index.html in a modern browser. Keep the assets folder beside all HTML files.

HOW TO PUBLISH ON GITHUB PAGES
1. Upload all six HTML files, the assets folder and this README to the repository root.
2. In GitHub, open Settings > Pages.
3. Select Deploy from a branch, choose main and /(root), then Save.
4. Wait for the Pages URL to appear. The homepage is index.html.

BEFORE PUBLISHING — PLEASE VERIFY
- Business hours currently reflect the details previously supplied: Saturday–Thursday 24 hours; Friday closed.
- Verify the three phone numbers and WhatsApp number.
- Confirm the exact Facebook page URL if you want it added.
- Confirm brand availability and product stock; product pages intentionally avoid unverified model numbers/prices.
- Replace the illustrative project gallery images with real Taj Solar project photographs. The projects page explicitly labels them as illustrative.
- Confirm that the Google Maps pin matches the office address.

NOTES
- No build tools, React, Node, Tailwind or server are required.
- The contact form opens WhatsApp with the enquiry pre-filled; it does not store or transmit form data to a website backend.
- The solar calculator uses a simple indicative estimate (monthly units / 120). It is not an engineering calculation or a quotation. Change this assumption only after confirming the company's preferred sizing method.
- Fonts and photographs load from external providers, so internet access is needed for those assets.
